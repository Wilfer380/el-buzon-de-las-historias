# Workshop flow

1. The landing page identifies the workshop and its organizer.
2. A participant route is addressed by session code.
3. Organizer and projection routes are addressed by session ID.
4. In B1, all three are explanatory placeholders: they neither collect nor display community contributions.

A later slice can define session creation and access rules before adding data services. QR entry, authentication, moderation, realtime projection, and deployment remain future decisions.
